# backEndProjCarros


### 1º Baixa do repositório: https://github.com/CCSoftwarern/backEndProjCarros.git
### 2º entra no repositorio: 
### cd backEndProjCarros -> cd backendlojacarros
### 3º Cria a env: python -m venv .venv
### 4º Ativa a env: .venv\Scripts\activate
### 5º Instala as Dependências: pip install -r requirements.txt
### 6º Se não existir a tabela carros, cria com o comando:
### python manage.py makemigrations 
### python manage.py migrate
### 7º Rodar o servidor:  python manage.py runserver 8080
### 8º Para desativar env: deactivate

***O banco carros já deve existir dentro do mysql ***
